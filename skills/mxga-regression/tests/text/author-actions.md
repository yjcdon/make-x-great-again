# 作者快捷操作

## AUTHOR-05 切换并恢复关注关系

- **前提与步骤**　使用获准关注和取关的测试对象。先在其帖子三点菜单记录初始操作，再点快捷按钮切换关系，重开菜单核对。结束或中途出错时核对当前关系，若已改变则恢复，并再次打开菜单确认。
- **预期结果**　快捷按钮和原生菜单均变为反向操作，恢复后两者均与初始状态一致。缺少授权目标时记未验证。

## AUTHOR-06 作者人数

- **前提与步骤**　在他人卡片上，按相同显示精度与同一作者的原生主页或悬浮卡逐项比对。
- **预期结果**　正在关注数和关注者数分别与原生信息一致。

## AUTHOR-07 切页后的卡片

- **前提与步骤**　离开回复区再返回，在受影响的搜索、书签、通知、帖子活动「引用」等入口重复观察。
- **预期结果**　本人卡片只有标题行的复制图标，他人卡片的复制与屏蔽同排，按钮各出现一次，目标是当前作者。
