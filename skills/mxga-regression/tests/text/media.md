# 图片与视频

## MEDIA-01 Typora 图片展示

- **前提与步骤**　按变更范围将三图帖或带封面和正文图的文章复制到 Typora，对照原帖图序或原文相邻段落。
- **预期结果**　三图帖的三张图依次显示。文章封面显示在标题后，正文图显示在原来的段落位置。
- **关联脚本**　`COPY-05`、`ARTICLE-06`

## MEDIA-02 作者自填图片描述

- **前提与步骤**　选有作者自填描述的图片帖，复制后查看 Markdown 图片的替代文字。
- **预期结果**　替代文字保留作者填写的描述。

## MEDIA-03 视频播放

- **前提与步骤**　将普通视频帖及三段视频文章分别粘贴到 Typora，在原位置逐段点播放。对普通帖另核对页面已加载的 MP4 地址。
- **预期结果**　各段位置对应且播放进度前进，普通帖的视频地址与页面数据一致。
- **关联脚本**　文章位置见 `ARTICLE-07`
