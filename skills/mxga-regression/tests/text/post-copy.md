# 全文复制

## COPY-FEEDBACK-01 复制按钮位置与反馈

- **前提与步骤**　从本次涉及的入口点复制，包括时间线、搜索、主页、帖子详情、回复、文章等。观察图标和相邻按钮，核对按钮的无障碍名称。
- **预期结果**　图标可见且能点中。在本人主页紧邻 Grok，在他人主页与屏蔽同排。点击后原位显示对勾和名称「已复制」，约一秒后恢复复制图标和「复制全文」，相邻按钮位置稳定。
- **关联脚本**　主页布局见 `AUTHOR-01`、`AUTHOR-02`

## COPY-07 自己的折叠图文帖
