# 0.1.1 · 评论区快捷操作

2026-11-11

## S · 背景

首页已经能直接操作作者，点进帖子后，评论作者仍要通过 X 原有的资料卡或菜单操作。首页有些关注人数也只显示缩写。

## T · 目标

沿用首页的操作方式处理评论作者，让人数和按钮位置更容易读懂。

## A · 做法

将关注、取关和屏蔽接入评论卡片，并显示正在关注和关注者人数。用完整数字显示人数，避免悬浮资料卡覆盖帖子上的计数。把屏蔽和首页各标签的「不感兴趣」图标排到与关注按钮同一行。

## R · 结果

用户可以在评论卡片上直接判断和操作作者。首页的反馈入口覆盖各标签，具体操作取决于 X 为该帖提供的菜单。
