# 0.5.1 · 普通帖回复加载与翻译

2026-11-23

## S · 背景

普通帖的回复会陆续加载。部分卡片出现后，屏蔽、关注信息和 Grok 翻译入口可能迟到或缺失。

## T · 目标

让回复卡片及时显示能用的操作，同时控制首屏和滚动期间的重复处理。

## A · 做法

识别回复卡片后先显示屏蔽，X 返回作者数据后再更新关注按钮和人数。让普通帖的回复使用 X 原生翻译，滚动时增量处理变化的卡片，复用 X 已有的数据响应。

## R · 结果

发布前在 macOS Chrome 的两条普通帖中实测了回复快捷操作、Grok 原文与译文切换，以及滚动加载。关注信息随作者数据补齐，翻译请求仍由用户点击后交给 X 发起。
