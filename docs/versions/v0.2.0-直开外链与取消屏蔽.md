# 0.2.0 · 直开外链与取消屏蔽

2026-11-15

## S · 背景

帖子和文章的外链常先经过 `t.co`。从快捷入口打开屏蔽确认框后，点取消有时还会留在三点菜单里。

## T · 目标

点击已有完整地址的链接时直达目标网站，取消屏蔽后回到帖子。

## A · 做法

利用 X 已提供的完整网址改写帖子与文章中的短链，缺少完整网址时沿用原地址。处理屏蔽确认框取消后的菜单收起逻辑。

## R · 结果

能解析的外链可以直接打开。首页、评论区和通知页中，取消屏蔽会收起帖子菜单并回到原帖。
