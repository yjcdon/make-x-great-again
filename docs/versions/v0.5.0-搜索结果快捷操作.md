# 0.5.0 · 搜索结果快捷操作

2026-11-18

## S · 背景

搜索结果也是帖子列表，但缺少首页已有的作者信息和快捷操作。X 给搜索结果提供的反馈是「这个帖子没有帮助」。

## T · 目标

在结果卡片上直接查看和操作作者，反馈与搜索页的原生选项一致。

## A · 做法

复用帖子卡片的关注、取关、人数和屏蔽逻辑。搜索结果的反馈图标调用 X 原生「这个帖子没有帮助」，翻译和外链沿用现有处理。

## R · 结果

用户可以留在结果页操作作者、反馈和翻译。发布记录包含 Node.js 22 安装包与脚本初始化检查，以及搜索卡片和反馈菜单的模拟验证。
