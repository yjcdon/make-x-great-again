# 0.3.0 · 统一快捷操作与外链逻辑

2026-11-15 · 源码版本

## S · 背景

外链直开已经覆盖帖子和文章正文，个人主页的帖子和外链预览卡片仍有遗漏。随着页面覆盖增加，数据读取、链接改写和按钮维护也集中在同一脚本里。

## T · 目标

补齐个人主页和预览卡片的外链处理，把各页面共用的代码整理到便于复用的模块里。

## A · 做法

将 X 数据读取、外链解析、原生菜单和帖子快捷操作拆成独立模块，由入口脚本统一调度。同一帧内合并刷新，预览卡片复用已解析的短链目标。

## R · 结果

源码覆盖了个人主页帖子和预览卡片中的外链，并为后续列表翻译提供了共享的入口。GitHub 的 0.4.0 安装包包含了这一轮改动。
