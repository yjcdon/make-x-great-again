# 0.1.2 · 通知页作者快捷操作

2026-11-11

## S · 背景

从通知页查看相关帖子时，卡片缺少首页和评论区已有的作者信息与操作。

## T · 目标

打开通知后，可以在遇到的帖子卡片上直接处理作者关系。

## A · 做法

把关注、取关、关注人数和屏蔽接到通知页的帖子卡片上。继续用 X 原生确认框处理屏蔽。

## R · 结果

用户在通知页的帖子卡片上就能查看作者的正在关注和关注者人数，或直接关注、取关和屏蔽。
