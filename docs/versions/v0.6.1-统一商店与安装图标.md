# 0.6.1 · 统一商店与安装图标

2026-11-27

## S · 背景

0.6 的 Chrome 商店页面已经换成红色 X，安装包仍使用旧的青色 GA 图标。安装时，商店页面和 Chrome 的安装提示显示了两种样式。

## T · 目标

让 Chrome 商店、安装后的扩展和 GitHub 使用已确认的红色 X 图标。

## A · 做法

把源码中已有的 16、32、48、128 像素四张红色 X 图标打进 0.6.1 ZIP。GitHub 首页引用同一个 128 像素文件。GitHub Release 和 Chrome 商店使用同一份安装包。

## R · 结果

逐个核对了安装包里的四种图标尺寸和颜色，确认功能文件与 0.6 逐字节一致。GitHub 已发布 0.6.1，同一安装包已提交 Chrome 商店审核。

[GitHub Release](https://github.com/yjcdon/make-x-great-again/releases/tag/v0.6.1)
