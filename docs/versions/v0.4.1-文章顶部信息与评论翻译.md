# 0.4.1 · 文章顶部信息与评论翻译

2026-11-15

## S · 背景

X 文章的发布时间和查看次数在文末，读长文时要滚动才能看到。文章评论也缺少列表里已经有的翻译入口。

## T · 目标

阅读前就能看到文章的基本信息，读评论时可以在原处翻译。

## A · 做法

将原生信息条呈现在标题下方，保留文末那条信息的悬停和点击操作。为符合条件的文章评论启用 X 原生「显示翻译」。

## R · 结果

打开文章即可在标题下看到发布时间和查看次数。文章评论支持按需翻译和切回原文。
