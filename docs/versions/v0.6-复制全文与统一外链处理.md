# 0.6 · 复制全文与统一外链处理

2026-11-26

## S · 背景

把 X 内容复制到笔记时，需要手动展开长帖、补全截断链接和整理文章结构。图片和视频也容易丢失。快捷按钮在帖子详情、个人主页等位置的覆盖不一致，悬浮资料卡也有外链仍经过 `t.co`。

## T · 目标

让用户在常见页面一键复制帖子或文章。普通帖保留当前阅读语言，文章保留可继续编辑的结构与媒体。点击与复制共用完整网址，复用 X 已加载的数据并控制滚动开销。

## A · 做法

- 统一使用复制图标，复制成功后短暂显示勾。普通帖优先使用当前显示的原文或译文，X 已加载对应全文时直接复制折叠内容。
- 将文章导出为 Markdown，保留标题、段落、列表、引用、代码和链接。图片输出为 Markdown，视频用 X 已提供的 MP4 地址嵌入，保留媒体原有顺序和位置。
- 在帖子详情、个人主页、书签和帖子活动的「引用」等页面复用作者快捷操作。自己的普通帖显示复制图标，其他反馈入口按 X 原生菜单提供的能力展示。
- 用同一套规则补全正文、预览卡片、个人简介和悬浮资料卡里的短链。增量处理新增链接，并把解析结果供复制使用。

## R · 结果

在 macOS Chrome 实测了普通视频帖、折叠图文帖、外链预览、三图帖和两篇文章。将内容粘贴到 Typora，确认多图可以按原顺序显示，同一篇文章的三段视频都可在原位置点击播放。折叠全文和直接嵌入视频依赖 X 已提供的正文或 MP4 地址。
