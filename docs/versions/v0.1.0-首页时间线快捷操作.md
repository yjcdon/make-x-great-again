# 0.1.0 · 首页时间线快捷操作

2026-11-10

## S · 背景

刷 X 首页时，查看作者关注人数通常要打开资料卡，屏蔽和「不感兴趣」也要进入帖子菜单。

## T · 目标

把判断作者是否值得关注、处理不想再看到的内容所需的操作放到首页帖子卡片上。

## A · 做法

在作者名下加入关注、取关和关注人数，在三点菜单旁加入屏蔽和「不感兴趣」入口。屏蔽调用 X 的确认框，「不感兴趣」调用「为你推荐」里的原生反馈并沿用撤销入口。

## R · 结果

首版将这些操作带到 X 首页时间线，并打包了 MXGA 像素图标。GitHub 提供了可在 Chrome 111 及以上手动加载的 ZIP。
