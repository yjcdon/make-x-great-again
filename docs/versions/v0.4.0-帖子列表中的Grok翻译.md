# 0.4.0 · 帖子列表中的 Grok 翻译

2026-11-15

## S · 背景

X 自带 Grok 翻译，但在首页时间线等帖子列表里，符合翻译条件的帖子也可能缺少「显示翻译」入口。

## T · 目标

刷列表时可以停在原帖上看译文，并随时切回原文。

## A · 做法

在符合 X 翻译条件的卡片里启用原生「显示翻译」，入口放在正文上方。点击后才由 X 发起翻译，译文和切回原文继续由 X 渲染。

## R · 结果

符合条件的外语帖可以在列表里切换原文和译文。此版还发布了 0.3.0 已整理的外链处理，覆盖个人主页帖子和外链预览卡片。

[GitHub Release](https://github.com/yjcdon/make-x-great-again/releases/tag/v0.4.0)
