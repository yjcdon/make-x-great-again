# 0.1.3 · 自己的帖子与原生反馈

2026-11-12

## S · 背景

作者快捷操作出现在自己的帖子和回复上时没有实际用途。「不感兴趣」的快捷入口也曾干扰 X 自己的反馈界面。

## T · 目标

根据当前登录账号决定是否展示作者操作，让 X 完成原生反馈流程。

## A · 做法

识别当前账号，在自己的内容上隐藏扩展快捷操作和关注人数。「不感兴趣」交由当前帖子的原生菜单处理，反馈提示和撤销交由 X 展示。

## R · 结果

自己的帖子和回复恢复为 X 原生界面。首页继续提供快捷反馈，并沿用 X 的提示和撤销操作。
